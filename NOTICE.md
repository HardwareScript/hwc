Algorithms and Prior Art:

Hardware Script is built upon well-established, public domain algorithms:

- A* pathfinding (Hart, Nilsson, Raphael, 1968)
- Manhattan routing (Hightower, 1969)
- Lee's algorithm (C.Y. Lee, 1961)
- Morton Z-order curves (G.M. Morton, 1966)
- Design rule checking (Mead & Conway, 1980)
- SPICE netlist representation (Nagel, 1973)
- Bresenham's line algorithm (Bresenham, 1962)

These algorithms are in the public domain and cannot be patented.
