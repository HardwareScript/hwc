# Hardware Script Governance and Commitment

## Founder's Commitment

Hardware Script is being built as **permanent open source infrastructure** for the hardware design community. This document establishes the governance principles and long-term commitment to ensure the project remains free and open.

### Core Principles

1. **Not For Sale**: Hardware Script will never be sold to a corporation or private entity
2. **Perpetual Open Source**: The AGPLv3 license is irrevocable and permanent
3. **Community First**: The project exists to serve hardware designers, not shareholders
4. **Long-term Stewardship**: Governance structures will outlive the founder

## Current Ownership

**Copyright Holder**: Olowookere Olamide (Founder)

As the sole creator and copyright holder, I commit to:
- Maintaining Hardware Script under AGPLv3 in perpetuity
- Never selling the project or its intellectual property to a private entity
- Establishing a foundation or non-profit organization to ensure long-term stewardship
- Protecting the community's interests above commercial opportunities

## Future Governance Structure

### Phase 1: Individual Stewardship (Current)
- Olowookere Olamide holds copyright and makes all decisions
- Community input welcomed through GitHub issues and discussions
- Transparent development process

### Phase 2: Foundation Establishment (Planned)
When the project reaches maturity, ownership will be transferred to a **non-profit foundation** with the following characteristics:

- **Structure**: 501(c)(3) non-profit or equivalent
- **Purpose**: Protect and advance Hardware Script as open source infrastructure
- **Control**: Founder retains board seat and veto power on license changes
- **Mission**: Ensure Hardware Script remains free, open, and community-driven
- **Funding**: Through donations, grants, and optional commercial licensing

### Why a Foundation?

A foundation structure ensures:
- **Cannot be acquired**: Non-profits cannot be purchased by corporations
- **Tax benefits**: Donations are tax-deductible, enabling sustainable funding
- **Legal protection**: Shields contributors and users from liability
- **Perpetual existence**: Outlives any individual founder or contributor
- **Community trust**: Demonstrates commitment beyond personal gain

## Safeguards Against Acquisition

### Legal Protections
1. **AGPLv3 License**: Cannot be revoked, even if ownership changes
2. **Patent Grant**: Irrevocable, protects all users permanently
3. **Foundation Structure**: Non-profits cannot be "acquired" in traditional sense
4. **Community Fork Rights**: Anyone can fork if governance fails

### Transparency Commitments
- All major decisions documented publicly
- Financial reports published annually (once foundation exists)
- Governance changes require community input
- No secret deals or private negotiations

## Inspiration and Precedent

Hardware Script follows the model of successful infrastructure projects:

- **Rust**: Mozilla → Rust Foundation (independent non-profit)
- **Python**: Guido van Rossum → Python Software Foundation
- **Linux**: Linus Torvalds → Linux Foundation
- **Blender**: Community → Blender Foundation

These projects prove that founder-controlled foundations can protect open source infrastructure while enabling sustainable development.

## Commercial Licensing Model

Hardware Script uses **dual licensing**:

1. **AGPLv3** (Free): For open source projects and public work
2. **Commercial License** (Paid): For proprietary/closed-source hardware development

**Important**: Commercial licensing revenue will:
- Fund foundation operations and development
- Support community initiatives and documentation
- Pay core maintainers fairly
- **Never** enrich private shareholders or investors

This is a **sustainability model**, not a profit-extraction model.
